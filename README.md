## Фрагмент реальной монорепы

Фрагмент одной из множества app из одной большой монорепы. Конкретно тут таблица актов с фильтрами, а так же все 
компоненты с формами относящимся к актам. Форма представляет собой обертку с табами, каждый таб содержит раздел
формы. Все компоненты форм, табы, таблица, различные директивы созданы на основе собственной библиотеки компонентов 
компании.

Весь код максимально обезличен. Все префиксы компонентов, директив и всего того, что может указывать на 
компанию, заменены на **test**
